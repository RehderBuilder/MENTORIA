O que é a mentoria

Seu guia para o Cursor

O Cursor é um editor baseado no VS Code com IA integrada. Nossa mentoria ajuda você a instalar, configurar e usar os modos Ask, Agent e Composer com confiança — sem se perder em funcionalidades avançadas no primeiro dia.

02

Entenda o layout, o painel de chat e os atalhos que aceleram seu fluxo diário.

03

IA na prática

Use Chat, Agent e autocomplete para escrever, revisar e refatorar código com segurança.

Trilha de aprendizado

Do download ao primeiro código com IA

Siga esta sequência após assistir aos vídeos. Cada módulo leva cerca de 15 a 30 minutos na prática.

  1. 1

    Download e instalação

    Acesse cursor.com, baixe para seu sistema operacional e faça login.

    File → Open Folder
  2. 2

    Conheça a interface

    Explore o explorador de arquivos, o terminal integrado e o painel lateral de IA.

  3. 3

    Modo Ask (somente leitura)

    Use Ctrl+L para perguntar sobre o código sem alterar arquivos.

  4. 4

    Modo Agent

    Pressione Ctrl+I, descreva uma tarefa e revise as alterações no diff.

  5. 5

    Regras e boas práticas

    Crie arquivos em .cursor/rules/ para orientar a IA sobre padrões do seu projeto.
